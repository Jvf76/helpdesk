# Clarity Desk — frontend

Frontend React para uma central de helpdesk com login e fila de chamados priorizada por IA.

## Executar

```bash
npm install
npm run dev
```

O login atual é demonstrativo: use o usuário `adm123` e a senha `adm123`. Os chamados são dados locais de exemplo, já ordenados por prioridade. Para integrar o backend, substitua a constante `tickets` e a função de login em `src/App.jsx` pelas chamadas à API.
